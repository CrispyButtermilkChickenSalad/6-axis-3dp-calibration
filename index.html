MACHINE + BED

In 6-axis adaptive tool-rotation mode, C follows the bead heading and is kept within these physical limits. Unsupported headings are rejected; limits are never bypassed. Bed rotation wraps C to ±180° and ignores tool-axis limits.

PRINT + MATERIAL

Adaptive tilt requires 5+ axes. On a 6-axis adaptive tool rotation, C follows the bead heading and uses the nearest angle inside the configured physical limits; headings with no valid equivalent are rejected. Bed rotation wraps C and skips tool-axis limits. Neither mode solves machine-specific inverse kinematics or moving-bed XY compensation.
